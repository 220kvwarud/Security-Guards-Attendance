WARUD SECURITY ATTENDANCE – PWA PACKAGE

To install on Android:
1. Upload the complete folder contents to an HTTPS hosting service (for example, a static website host).
2. Open the hosted HTTPS address in Chrome on Android.
3. Open Chrome menu (three dots) and choose Install app or Add to Home screen.
4. Launch Warud Attendance from the new home-screen icon.

The service worker enables offline app loading after the first successful online visit.
Attendance records are saved in the browser on that device. Use Backup JSON regularly and store copies separately.
The package starts with the six guard records previously available. Your personal JSON backup has not yet been imported; use Restore Backup in the app to import it.
Excel / CSV Export creates a CSV file that opens in Microsoft Excel.
